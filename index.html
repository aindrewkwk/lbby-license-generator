Getting Started

From download to your first server in minutes.

1. Install Lbby

Download the installer for your operating system from the Download section above. Run the installer and follow the prompts.

  • Windows: Run the .msi installer
  • macOS: Open the .dmg and drag to Applications
  • Linux: Install the .deb, .rpm, or run the .AppImage

2. Create Your First Server

Open Lbby and the setup wizard will guide you:

  • Choose a server name and folder
  • Pick your Minecraft version
  • Select a server type (Paper is recommended for most users)
  • Set RAM allocation (2–4 GB is a good start)
  • Click Start — Lbby downloads everything automatically

3. Play with Friends

To let friends join over the internet:

  • Go to the Tunnel tab
  • Enable the playit.gg tunnel
  • Share the generated address with your friends
  • No port forwarding or static IP required!

4. Install Mods & Plugins

Head to the Mods tab to browse Modrinth:

  • Search for mods/plugins compatible with your server type
  • Click Install — Lbby handles placement and restarts
  • Auto-update notifications when new versions are available

Server Types

Lbby supports 11 server types. Here's a quick guide:

  • Paper — Optimized, plugin support. Best for most servers.
  • Fabric — Modern mod loader. Great for performance mods.
  • Forge — Classic mod loader. Largest mod ecosystem.
  • Purpur — Paper fork with extra features and customization.
  • Folia — Multithreaded Paper for massive servers.
  • NeoForge — Modern fork of Forge with active development.
  • Vanilla — Pure Minecraft, no mods or plugins.
