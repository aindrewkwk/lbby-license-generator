Lbby License Generator — For admin use only

This tool generates Ed25519-signed JWTs for the Lbby app license system.

Private keys are stored in your browser's localStorage and never sent to any server.

Generated JWTs can be activated in the Lbby app via the License tab → Advanced → Paste JWT.
