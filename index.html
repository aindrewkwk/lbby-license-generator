Lbby Docs

Get up and running, then master every feature.

Getting Started

  1. Install Lbby — Download the latest release for your platform from the Download section above. The app is a standalone native binary — no dependencies required.
  2. Create Your Server — Open Lbby and click New Server. Choose a name, select a Minecraft version, and pick a server type (Vanilla, Paper, Fabric, Forge, or Spigot). Lbby handles the rest — downloading the JAR, creating the folder structure, and generating configuration files.
  3. Start & Connect — Hit Start on your server card. Lbby launches the server and automatically sets up a public address using playit.gg — no port forwarding needed. Share the provided address with friends so they can join.

Server Types

  • Vanilla — The official Minecraft server software. No mods, no plugins — pure gameplay. Best for small friend groups who want the stock experience.
  • Paper — A high-performance fork of Spigot with additional optimizations and bug fixes. Supports plugins via the Bukkit/Spigot API. The recommended choice for most servers.
  • Fabric — A lightweight, modern mod loader. Ideal for clientside and serverside mods. Large mod ecosystem with tools like Sodium, Lithium, and Iris.
  • Forge — The original Minecraft modding platform. Supports large modpacks and complex modding frameworks. Best for heavy modpack servers.
  • Spigot — A CraftBukkit fork with performance improvements and plugin support. A solid choice for plugin-based servers.

Player Management

Whitelist — Enable the whitelist from the server dashboard to restrict who can join. Add players by their Minecraft username. Whitelisted players are stored in whitelist.json.

Ops (Operators) — Grant operator privileges to trusted players. Ops can run server commands, manage players, and change game settings. Managed through the Ops panel in Lbby.

Bans — Ban players by username or IP address. Banned players are stored in banned-players.json and banned-ips.json. Manage bans from the Players panel.

Mods & Plugins

Installing Mods — For Fabric and Forge servers, drop .jar mod files into the mods folder inside your server directory. Lbby displays the server path in the server settings. Restart the server after adding mods.

Installing Plugins — For Paper and Spigot servers, drop .jar plugin files into the plugins folder. Plugins are loaded automatically on server start. Popular sources: Modrinth, Hangar, SpigotMC.

Modpacks (Forge) — Forge supports full modpacks. Download a modpack's server files, extract them into your server directory, and ensure the Forge version matches. Lbby will detect and launch the correct JAR.

Backups

Automatic Backups — Lbby can automatically create backups of your world data on a configurable schedule. Enable auto-backups in server settings. Backups are stored locally and can be restored with one click.

Manual Backups — Create a snapshot of your server at any time from the server dashboard. Useful before major changes like mod updates or world edits.

Restoring — Select a backup from the backups list and click Restore. The server will stop, the world data will be replaced, and you can restart. Always stop the server before restoring.

Performance Tips

  • Allocate Enough RAM — For Vanilla servers with a few players, 2–4 GB is sufficient. Modded servers (Forge/Fabric) may need 4–8 GB. Adjust in server settings. Avoid allocating more than 8 GB unless running large modpacks.
  • Use Paper for Better Performance — Paper includes hundreds of performance optimizations over Vanilla and Spigot. If you don't need Forge/Fabric mods, Paper is the best choice for a fast, stable server.
  • View Distance — Lower the view distance in server.properties (default is 10). For weaker hardware, 6–8 chunks is a good balance between performance and visibility.
  • Keep Software Updated — Always run the latest Minecraft server version and the latest version of Lbby. Updates include performance improvements and security patches.

playit.gg Troubleshooting

What is playit.gg? — playit.gg is a tunneling service that gives your local server a public IP address without port forwarding. Lbby integrates playit.gg automatically — you don't need to install or configure it separately.

"Failed to start tunnel" — This usually means the playit.gg binary is missing or outdated. Lbby manages this for you, but if you see this error: stop the server, restart Lbby, and try again. The app will re-download the binary if needed.

Friends Can't Connect — Make sure you're sharing the full address from Lbby (it looks like xx.playit.gg:PORT). The server must be running. If the address changed, re-share it — playit.gg addresses can change between sessions.

High Latency — playit.gg routes traffic through their servers, which adds some latency. If you and your friends are on the same local network, direct LAN connection (localhost or local IP) will be faster.

playit.gg Account — Using playit.gg through Lbby does not require a playit.gg account. For advanced features (custom domains, static IPs), you can create an account at playit.gg.
